# Magic stack

The main magic stack for GTNH-1.21.1 is:

- Ars Nouveau 5.13.x — spellcrafting, Source, rituals and magical automation.
- Malum 1.8.2 — Spirit Arcana, soul resources and a darker parallel progression.

Ars Nouveau is the accessible entry point. Malum supplies the independent spirit/soul path.

Magic is parallel to GregTech but cannot bypass LV through UHV. Advanced magical cross-mod recipes should consume appropriate industrial materials.

Both mods have 1.21.1 NeoForge releases.
